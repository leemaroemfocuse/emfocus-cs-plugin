# EMFOCUS CS Center 자동 유지보수 플러그인

CS Center 새 티켓을 근무 시간(09:30~18:30)에 5분마다 확인해 Windows 알림을 띄우고, 한 건씩 분석해 내부 메모로 남깁니다.

설치는 CS Center의 MCP 토큰 발급 화면에 나오는 "이 PC에 설치" 명령 한 줄로 합니다.

수동 설치:
```
claude plugin marketplace add leemaroemfocuse/emfocus-cs-plugin
claude plugin install cs@emfocus-cs -s user
```
