아래 내용을 그대로 출력하고 다른 도구는 호출하지 않는다.

```
== 사용 방식 (바꾸기: /cs:mode 1|2|3, 업데이트해도 그대로 유지)
자동 분석   새 티켓을 AI가 분석해 [AI 자동 분석] 내부 메모로 남기고, 메모가 등록되면 Windows 알림
알림만      새 티켓이 올라오면 알림만. AI 분석은 실행하지 않음
MCP만       알림·자동 분석 없음. "CS 내 새 티켓 보여줘"처럼 물어볼 때만 조회

== 백그라운드 자동 분석 (자동 분석 방식)
매일 09:30~18:30, 5분마다 새 티켓 확인. Windows 작업 스케줄러가 돌리므로 Claude 창을 안 켜도 됨
  (PC 켜져 있고 Windows에 로그인돼 있을 때만. 근무 시간 중 PC를 켜고 Windows에 로그인하면 그때 한 번 바로 확인.
   Claude 로그인과는 무관)
한 번에 1건씩 분석
티켓 상태·담당자는 그대로(접수). 다른 사람의 AI가 먼저 잡은 티켓은 건너뜀
이미 [AI 자동 분석] 메모가 있는 티켓은 다시 분석하지 않음
알림은 메모를 등록했을 때만 옴(새 티켓 발견만으로는 안 옴)
백그라운드 AI 권한: 티켓 조회, 분석 잠금, 내부 메모 등록(고객에게 안 보임),
                    등록한 소스 폴더 읽기만. 상태·담당자 변경, 고객 댓글, PowerShell 실행, 파일 쓰기 없음
실행 기록: %LOCALAPPDATA%\CsCenter\cs-auto.log

== 직접 실행
/cs:run                 내 프로젝트의 접수·재오픈 티켓 1건을 가져가 분석 → 내부 메모
/cs:run 3 | all         3건 | 전체(최대 100)
/cs:run 2 project=12    프로젝트 12만
/cs:run ticket=<ID>     그 티켓 하나만 분석(담당자·상태 그대로)
  직접 가져가기(/cs:run 숫자)는 본인 담당·진행으로 바뀜. 끊기면 다음 실행에서 이어서 처리
  소스·DB·상태·고객 댓글은 건드리지 않음. 메모 검토 후 개발은 직접 지시

== 켜기·끄기·확인
/cs:start [분] [project=ID]   예약 실행 켜기(기본 5분)
/cs:stop                      예약 실행 끄기(Claude를 다시 열어도 다시 켜지지 않음)
/cs:status                    도는지, 최근 결과 확인
/cs:setup                     프로젝트별 내 PC 소스 위치 다시 찾기(없으면 소스 없이 분석)
  작업 스케줄러에서 직접 지우면 다음에 Claude를 열 때 다시 등록됨. 끌 때는 /cs:stop

== 메모
AI 분석 메모는 삭제만 가능(수정 불가). 사람이 쓴 내부 메모는 작성자가 수정·삭제

== 업데이트·토큰
업데이트: 새 버전이 있으면 Claude를 열 때 바뀐 내용을 모아 보여 주고 물어봄(자동 업데이트 없음)
  1. 업데이트  2. 업데이트 안 함(이번 버전 건너뜀, 더 새 버전이 나오면 다시 물어봄)
  나중에 하기: /cs:update once | skip
토큰은 쓰는 동안 자동 연장, 30일 동안 안 쓰면 만료
만료되면 "CS MCP 연결 만료" 알림 → MCP 연결 관리에서 [재발급] → 같은 화면의 설치 문장 실행
필요 권한: 전체권한 토큰(자동 분석·직접 실행). 알림만·MCP만은 조회 토큰도 가능
```
